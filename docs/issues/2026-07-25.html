file-organizer · 文件管家
ComposioHQ · 自动分类、重命名、归档——从此桌面不再炸
⭐ 15K+ 仓库日常自动化零门槛
是什么：你告诉它"把下载文件夹里的图片按月份分、文档按类型分、重复的删掉"，它就去干活。不是AI陪你聊天——是AI替你动手整理文件。
最适合：桌面常年100+文件不敢看的人、多项目素材混在一起的人、每次找文件花5分钟以上的人。

npx -y skills@latest add ComposioHQ/awesome-codex-skills --skill file-organizer --agent codex --global

📌 实操示例
输入："用 file-organizer 整理 E:/Downloads 文件夹：PDF 和 Word 放「文档」，Excel 放「表格」，PNG/JPG 按年月分到「图片/2026-07」和「图片/2026-06」，重复文件标记但先别删，列出让我确认。"

📐 上下文窗口缩减与应对（7/18）
GPT-5.6 默认上下文从372K降到272K Token（缩减约27%）。影响：长时间会话中 AI 会更快"忘记"早期内容。应对策略：① 拆大任务为小块，一个会话只干一件事；② 定期用"总结当前进度"让 AI 压缩上下文；③ 拆分后的子任务丢给新会话（Codex 0.145已支持更稳定的会话握手和恢复）。
💡 本周技巧：用 Codex 的"先聊方案再动手"模式——复杂任务别直接丢过去，先说"帮我先做个计划，列出步骤和每步要用什么工具"，确认后再执行。这个习惯能让你少浪费一半时间在来回修正上。

NotebookLM 每日进步
🎧 Audio Overview 四种人格——同一份资料，听四遍，收获完全不同
多数人只知道默认的「双人播客（Deep Dive）」模式。实际有四种格式可切换：Deep Dive（双人深入讨论，默认）、The Brief（单人60秒精华）、The Critique（双人批判性审视你的材料）、The Debate（双人多角度辩论）。同一份研究报告，Deep Dive适合通勤听全貌，The Critique适合写论文前找漏洞，The Debate适合决策前看正反观点。
📹 YouTube一键转录——5分钟吃完1小时视频
把 YouTube 链接直接粘贴到 NotebookLM 的「来源」里，有字幕的视频自动拉转录稿。然后让它生成：① 章节大纲（3分钟定位关键段落）② 核心引述（直接引用原话）③ 与其他已存来源的矛盾点。一小时长视频，5分钟就抓住骨架了。没字幕的视频：下载音轨上传，NotebookLM 的 Studio → 转录稿。
📋 素材纪律法则：先跟大模型聊方向，再让 NotebookLM 整理
最佳实践：不要一上来就往 NotebookLM 扔30个素材然后问"我该写什么"。正确顺序：① 先跟 ChatGPT/Claude 讨论"想解什么问题、拆成哪几部分"；② 拿着这个方向去搜集素材、导入 NotebookLM；③ 问 NotebookLM 结构化问题（"这些素材在X问题上的一致/矛盾点是什么"）。NotebookLM 的核心优势是「基于已有材料回答、不瞎编」，把它当整理工具而不是创作工具。

WorkBuddy 实用技巧
⚡ 三要素指令公式：目标 + 输入 + 格式 + 约束 = 零返工
WorkBuddy 最实用的指令写法：做什么（目标）+ 在哪取数据（输入）+ 输出什么格式（格式）+ 有什么特殊要求（约束）。反例：「帮我做个报告」→ AI开始追问→来回三四轮。正例：「读取 data/ 里的Q2销售数据，按区域汇总销售额和增长率，生成柱状图+饼图，输出5页PPT，蓝色商务风，字号≥16pt」→ 一次出成品。

搭配 Plan模式 使用效果更好：重要任务先让 WorkBuddy 列出执行计划，你确认后再跑——避免花了时间发现方向不对。
🔗 Skill链式串联：多步骤一键自动跑
WorkBuddy 支持用 → 串联多个操作：比如"读取桌面项目资料 → 按主题分类归档 → 生成PPT汇报 → 存到指定文件夹"。这不是未来功能，现在已经可以用。把重复的「先整理→再生成→再分发」流程写成一条链式指令存为自动化，每天省30分钟。

实操模板：「读取 E:/项目素材/ 文件夹 → 按项目名分类归档到子文件夹 → 每个项目生成一份200字摘要 → 汇总成Excel进度表」。试试看，下周你就可以把它设成周五下午3点的定时自动化。

今日成果展示
🎯 20分钟焕新桌面 → 一键出研究简报
用 file-organizer + paperjsx 串联：把一团乱麻的项目资料变成整洁的文件夹 + 可交付的PPT报告
场景：你的桌面上散落着过去三个月的行业研报PDF、竞品截图PNG、自己写的笔记Word、会议录音——总共60多个文件，每次找东西都要搜半天。你想整理它们，顺便出份简报下周汇报用。

操作流程：
第1步（2分钟）：对Codex说——"用 file-organizer 整理桌面「行业研究」文件夹：PDF按来源机构分（麦肯锡/BCG/其他），截图按竞品名称分，笔记按日期归档，所有文件统一重命名为「日期-来源-标题」格式"
→ 文件夹从60+杂乱文件变成4个分类子文件夹，每个文件命名规范

第2步（5分钟）：对Codex说——"用 paperjsx 读取「行业研究/麦肯锡」文件夹里的3份最新报告，提取核心观点和数据，生成：① 8页PPT（封面+行业趋势总览+3页核心发现+竞争格局+建议+结尾），深蓝商务风；② DOCX摘要文档（含执行摘要）"
→ Skill 自动分析PDF内容，识别关键段落，生成JSON→渲染PPTX和DOCX

最终成果：一份整洁的行业研究文件夹 + 一份可直接用于内部汇报的8页PPT + 一份1500字DOCX摘要报告。全程不打开一个办公软件，不复制粘贴一行文字。

⏱️ 总耗时：约20分钟（其中AI处理15分钟，你只需要坐在旁边喝咖啡确认两次即可）
