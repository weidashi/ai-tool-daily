「听进去 · 聊清楚 · 讲出来」：5 个新 Skill 打通内容工作者的输入输出

音频转文字 · 播客观点研究 · 反向拷问 · 进度交接 · PPT 讲稿
📌 本期导读
做内容最耗神的往往不是写正文，而是输入到输出之间的几道「暗缝」：听到的音频怎么变成能引用的文字？听完一期播客怎么沉淀成观点？动手前怎么把思路先问清楚？写一半明天怎么接着写？PPT 做完了怎么配讲稿？这期 5 个全新 Skill 正好补上这些缝，全是 0 行代码的日常知识工作。
📘
Codex 日常效率 Skills
①
grill-me（反向拷问）
Matt Pocock · mattpocock/skills 合集 · 动手前先采访你
⭐ 190k+ 合集选题诊断写作规划
是什么：写文章、做方案之前，AI 反过来一次一个问题地采访你，还常给你一个「建议答案」照着选。它把「到底要写什么、给谁看、结构怎么搭」逼你当场想清楚，再动笔。
最适合：每次对着空白文档发呆、写着写着跑题、或选题还没想透就急着写的人。
📦 安装
npx -y skills@latest add mattpocock/skills --skill grill-me --agent codex --global
装完重启 Codex；在对话里直接描述你要写的东西，它就会开始逐题追问。
🎯 今天就能试：把下周要写的公众号选题丢给它，回答它 3-5 个问题，先拿到一份清晰大纲再动笔。
📌 实操示例
输入：「我想写一篇『AI 时代普通人怎么保持竞争力』的公众号文章」
成果：它会逐题问——读者是谁？他们最大的困惑是什么？你最想反驳的流行观点是哪条？你有哪些亲身案例？答完直接给出一份带钩子、分论点、案例位的大纲，写完不易跑题。
②
handoff（会话交接）
Matt Pocock · mattpocock/skills 合集 · 进度压成一份交接文档
⭐ 190k+ 合集进度管理写作续写
是什么：把当前对话里做过的决策、待办事项、写到哪一步，压成一份 Markdown 交接文档。开新会话、换模型、或第二天接着写，都不会丢上下文、不用从头解释。
最适合：长文写作、多日连载、需要隔天续写的场景。
📦 安装
npx -y skills@latest add mattpocock/skills --skill handoff --agent codex --global
装完在对话里输入 /handoff 或直接让它「生成交接文档」。
🎯 今天就能试：写完一段文章后输入 /handoff，把进度存成文档，明天开新会话继续写。
📌 实操示例
输入：「/handoff」
成果：一份 Markdown 交接文档——已完成：前三节正文 + 引用的 3 篇文献；待办：补第 4 节案例、写结尾金句；下一步：先找两组对比数据。换会话粘贴即可无缝续写。
③
podcast-research-skill（播客观点研究）
winnieAI123 · 播客搜索 + 本地转写 + 观点分析
🎙️ 音频研究选题研究阅读总结
是什么：搜索播客、本地 Whisper 转写、做观点分析，最后输出一份「观点简报」Markdown 报告——主导观点、核心分歧、逐集摘要，且每条引用都标注来源和说话人。
最适合：做行业调研、竞品观察、选题储备时，把「听播客」从耳朵里过一遍变成可检索、可引用的素材库。
📦 安装
npx -y skills@latest add winnieAI123/podcast-research-skill --agent codex --global
首次用会下载本地 Whisper 模型（约 0.5-1.6GB），之后本地转写不再收费。
🎯 今天就能试：用「AI 时代的知识工作者」为主题搜最近 30 天播客，选 3 集转写，拿到一份带引用的观点简报。
📌 实操示例
输入：「搜索主题『AI 时代的知识工作者』，分析最近 30 天的播客」
成果：一份 Markdown 观点简报——一句话结论 + 各方立场表（谁说了什么）+ 主要分歧 2-3 条 + 逐集摘要（3-5 点，逐条带引用）。可直接当选题素材或引用来源。

transcribe（官方音频转文字）
OpenAI 官方 · openai/skills curated · 录音/播客转可检索文本
⭐ 官方音频转写日常自动化
是什么：OpenAI 官方 skill，把会议录音、播客、访谈转成可检索文字；可切换「说话人分离」模式标注谁在说，长音频自动分块处理。转完即可搜索、复制、引用。
最适合：开会后不想自己整理纪要、想把录音/播客变成能翻能搜的文字的人。

🎯 今天就能试：把一段 30 分钟的会议录音丢给它，拿到带说话人标注的文字稿。
📌 实操示例
输入：「把这段会议录音转成文字，标注每位说话人」
成果：一份按说话人分段的文字稿，可直接搜索关键决策、定位某人的原话、复制成会议纪要。

Codex 官方动态 & 使用技巧
⚡ /export：一键把对话导出成 Markdown
CLI 0.148.0（8/18）新增 /export 命令，把整段 TUI 对话完整导出成 Markdown 到剪贴板或文件。对写作的人尤其实用——写完一篇文章后直接 /export，拿到一份带上下文、可直接当草稿继续改的 Markdown，不用手动复制粘贴。
⚡ 会话 fork + 归档：长文写作不迷路
同版本新增 codex exec fork（分支会话）和 resume 面板的归档/恢复功能。配合今天的 handoff skill，一篇长文可以在不同「分支」里试不同写法，跑偏了随时回到归档的旧会话，像 git 一样管理你的写作进程。
⚡ 模型迁移提醒：GPT-5.4 系列 8/31 退役
GPT-5.4 与 GPT-5.4-mini 将于 8/31 从 Codex 退役（ChatGPT 登录用户）。官方建议替换为 gpt-5.6-terra 和 gpt-5.6-luna。如果你在 workspace 默认设置或自动化任务里写死了旧模型名，记得在截止前改掉。

NotebookLM 每日进步
🧪 三栏工作流：素材 → 提问 → 成品
现在的 NotebookLM 是「左（Sources）→ 中（Chat）→ 右（Studio）」三栏：左栏放素材，中栏提问挖洞察，右栏直接生成报告/PPT 等成品。别再把它当普通问答——它的价值在右侧 Studio，能从你的资料里直接「生产」而不是只「回答」。
🧪 8/17 新功能：整本 Notebook 可复制
8 月 17 日起，可复制一整个 Gemini Notebook，连同 Studio 产物（Audio/Video Overviews、学习指南、闪卡、测验、Slide Decks）一起带走（个人聊天记录和笔记不复制）。做「模板笔记本」或复用研究框架时，直接复制再替换素材，不用每次重建。
🧪 源选择纪律：10 个优质源 > 40 个重叠源
输出质量直接取决于输入质量：优先一手源而非二手博客；避免三份来源重复同一组数据（会放大权重）；把最核心的权威源放在上传顺序最前。加完新源后，再跑一次「源地图」提示词，更新对整本 Notebook 内容的理解。

今日成果展示
🎯 一个能直接带走的小成果：一段 30 分钟播客 → 一份公众号选题清单
用今天的工具组合，把「听过的」变成「能写的」
① 转文字：用 transcribe 把一期 30 分钟播客转成文字（带说话人分离）
② 提观点：用 podcast-research-skill 提炼出「主导观点 + 2 条核心分歧 + 逐集摘要」
③ 定选题：用 grill-me 反向拷问，把观点聚焦成 3 个可写角度
④ 输出：一份公众号选题清单，示例——
选题 1：《为什么 AI 越强，会提问的人越值钱》——反驳「学工具就行」，用播客里两位嘉宾的分歧做钩子；
选题 2：《听完 30 分钟播客，我只记下这 3 个反常识结论》——把逐集摘要压缩成清单体；
选题 3：《别急着学 Prompt，先学会把一件事问清楚》——借用 grill-me 的「反向拷问」方法论。
transcribe 转文字→ podcast-research 提观点→ grill-me 定选题→ 公众号选题清单
🌱 输入决定输出的上限，工具决定你的下限——今天这 5 个 Skill 都在帮你把「下限」抬高一点。
