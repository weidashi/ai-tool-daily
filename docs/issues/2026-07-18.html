行业动态 · 三则快讯
⚡ 商汤发布「算电协同 Agent」：AIDC 效能标尺从 PUE 走向 TPW
商汤在 WAIC 发布算电协同 Agent，重新定义 AIDC 效能衡量标准——从关注电力使用效率的 PUE，转向关注「每瓦特产出多少 Token」的 TPW（Token Per Watt）。临港落地后，单位电力 Token 产出提升 80%，电费低于同地区 IDC 10%。信号：AI 竞争的下半场不只拼模型，也在拼「一度电换多少智能」。
📦 申通发布快递业首个智能体平台 SClaw：LLM + Agent + CLI 深度耦合
申通在 WAIC 发布快递行业首个智能体平台 SClaw，覆盖小件员数字分身、AI 数智客服、AI 路由规划三大场景，并开放 CLI 接口。LLM + Agent + CLI 深度耦合意味着——Agent 开始把根扎进物流的真实作业流程，而不只是「聊聊天」。
🚀 钛动科技 Navos 2.0：全球首批 AI 营销智能体
钛动科技发布 Navos 2.0——全球首批 AI 营销智能体。多智能体协同串联市场分析、创意生成、广告投放全链路，从「看数据」到「做决策」再到「执行投放」一气呵成。信号：智能体开始接管完整的商业闭环，而不是单点任务。

NotebookLM / 实用技巧：WAIC 给普通人的 3 个行动建议
① 用 RED Skill 找灵感：逛平台，像逛应用商店
不用懂技术也能跟上这次浪潮。每天花 10 分钟在小红书搜「RED Skill」「Vibe Coding」，看别人把 AI 做成了什么——灵感比教程更值钱。看到有趣的就直接下载体验，好的用法随手收藏，这就是你的「AI 技能灵感库」。
② 把 WPS 升级到 AI 版：体验「交付式办公」
打开 WPS 365 里的「灵犀」，把你手头最烦的文档任务交给它——基于你已有的文档和上下文直接产出可继续编辑的 PPT、保留公式的表格、支持审阅的文档。先跑通一次「AI 产出 + 人工审阅」的交付闭环，你就真正站在了拐点这边。
③ 让豆包跑通第一个自动化任务：从最小闭环开始
在豆包专业版的「办公任务」模式里，写一个最简单的 Skill（比如「把日报总结成三行」），让它自动识别、自动执行。不用追求一步到位——先让 AI 替你干完一件小事，你就能直观感受到「交付式 AI」和「聊天式 AI」的区别。
