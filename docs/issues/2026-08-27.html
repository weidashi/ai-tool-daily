让 AI 越写越像你：个人 IP 输出层的最后一公里

个人文风学习 · 表达规则 · X 平台分发 · 公众号全流程 · 合同体检
📌 本期导读
前几期我们把「读进去、写出来、发出去」的流水线补齐了，这期补上最容易被忽略的一环——「写得像你」和「发得多」。5 个新 Skill 全是 Codex 生态、0 行代码：先给 AI 立表达规矩、让它学你的文风，再把它变成 X 平台和公众号的内容小团队，最后用合同体检收尾，接单不踩坑。

Codex 日常效率 Skills
①
writing-style-skill（个人文风学习）
yzhao062 · AI 写 → 你改 → 自动抽规则 → 越写越像你
写作润色个人 IP文风沉淀
是什么：一个「可学习」的个人写作风格模板。AI 先写，你手动修改，系统观察你的改动后自动提取规则，持续更新 SKILL.md——你改得越多，它越懂你的文风。
最适合：想沉淀个人 IP、不想每次开新对话都重新交代「我的语气、禁用词、段落习惯」的内容创作者。
📦 安装
npx -y skills@latest add jzOcb/writing-style-skill --agent codex --global
装好后，把你过去写得好的一两篇文章作为样本喂给它，先建立文风基线。
🎯 今天就能试：把你最近一篇「写完总想再改一遍」的稿子丢给它，说「按我的写作风格改写这段」。
📌 实操示例
输入：一段你亲手写的旧稿 + 一句「以后就按这个语气写」
成果：以后每次让 Codex 写东西，开头不再「在当今时代」，而是有你的判断、你的停顿、你的细节。

agent-style（21 条表达规则）
yzhao062 · 从源头约束 AI 怎么说话
写作润色源头约束21 条规则
是什么：不是事后改写，而是装好 21 条表达规则，让 Codex 从生成第一句就「不啰嗦、去套话、术语一致、别一开口像说明书」。适合 Claude Code、Codex、Copilot、Cursor 多环境。
最适合：受够了「首先/其次/最后」「值得注意的是」「不仅…更…」的人——从源头就别让它写出来。
📦 安装
npx -y skills@latest add yzhao062/agent-style --agent codex --global
装好后无需特意触发，写内容时规则自动生效。
🎯 今天就能试：直接让 Codex 写一段产品介绍，对比装之前——套话明显变少。
📌 实操示例
输入：「帮我写一段介绍我们新课程的朋友圈文案」
成果：一句人话讲清楚课程给谁、解决什么、怎么报名，全程没有「赋能」「一站式」「划时代」。

NotebookLM 每日进步
🧪 双速研究：Fast Research 和 Deep Research 分工
2026 年的 NotebookLM 已经能上网了，但要用对：Fast Research 在搜索框里快速拉一批候选来源给你筛；Deep Research 会浏览多个站点、汇编成一份带引用的报告，可直接导入为来源。想快速扫 → 用 Fast，想从零建知识库 → 用 Deep。
🧪 Studio 的输出比你想的多：幻灯片可直接导出 PPTX
除了音频概览，Studio 还能从你的来源生成思维导图、信息图（10 种预设风格）、闪卡、测验，以及能导出成 PPTX 的幻灯片大纲。做分享、做汇报，别只盯着「音频」这一个按钮。
🧪 最高价值的一句提问：「我的来源之间在哪里互相矛盾？」
多数人只会让 NotebookLM「总结」，但真正的高质量洞察藏在冲突里。这句提问会逼它找出不同来源的分歧点——这往往才是你写深度文章时最该抓住的角度。

今日成果展示
🎯 一个能直接带走的小成果
用 agent-style + writing-style-skill 两步，把一段「AI 腔」导语改回你自己的声音
改之前（典型 AI 腔）：「在当今快节奏的时代背景下，AI 正在深刻改变内容创作的方式。值得注意的是，对于每一个内容创作者来说，这不仅仅是一个工具的升级，更是一场关于表达方式的革命。」

改之后（你的声音）：「AI 把写稿速度提上来了，但三个月后回头看，我的文章都长一个样。这不是工具的问题，是我从没告诉它我该怎么说话。」

拆成一条 X 推文：「AI 写稿越来越快，读起来却越来越不像我。解法不是把『AI 味』改掉，而是让 AI 先学会我怎么说话——规则 + 样本 + 持续改。你改得越多，它越像你。」

先用 agent-style 立规矩，再用 writing-style-skill 沉淀文风，一段套话就变成了「有判断、有停顿、像你」的成品，顺手拆成 X 推文，一处产出、两处可用。
🌱 写作的最高境界不是「像人写的」，而是「像你写的」
