PPT-Skill — 多阶段智能PPT生成
Githubfans518（ken861222）· 7阶段流水线，从需求调研到演讲稿全自动
⭐ 新发布（6月）PPT生成MIT开源
是什么：不是又一个「一键套模板」的AI PPT玩具，而是一条从需求调研到最终交付的完整内容生产流水线。你给它一个主题，它像专业咨询团队那样跑完7个阶段——上下文收拢→需求调研→结构化大纲→逐页资料搜集→页面策划稿→SVG设计稿→PPTX导出→演讲稿。
最适合：需要高质量、有逻辑深度的汇报PPT，尤其适合国企战略汇报、项目提案、融资路演等场景。
亮点：金字塔原理组织内容 + 便利贴法可视化大纲 + Bento Grid 7种布局 + SVG可导入Office编辑。跟CyberPPT的「先分析再设计」理念一脉相承，但PPT-Skill更强调逐页独立研究——不是搜一次总资料，而是按每页主题单独检索，信息密度更高。
📦 安装
git clone https://github.com/ken861222/PPT-Skill.git ~/.codex/skills/PPT-Skill
PPTX导出需安装依赖：pip install python-pptx cairosvg Pillow
🎯 今天就能试：给它一个主题「国企改革三年行动方案汇报，目标受众是集团董事会」，它会先做需求调研确认使用场景和目标，再逐页规划内容，最后输出可编辑的PPTX+逐页演讲稿。
📌 实操示例
输入：帮我做一个关于「公司Q2业绩汇报」的PPT，受众是董事会，场景是季度经营分析会，需要包含财务数据、业务进展和Q3规划
成果：阶段1确认使用场景和页数→阶段2用金字塔原理出便利贴式大纲（封面→Q2核心结论→财务亮点→业务亮点→不足与风险→Q3规划→总结）→阶段3逐页联网搜集行业对标数据→阶段4每页策划稿含核心观点+支撑数据→阶段5 SVG设计稿（商务深色配色）→阶段6可编辑PPTX文件→阶段7逐页30-60秒演讲词。全过程15-30分钟，咨询级交付。

redya-xiaohongshu — 红鸦小红书图文生成
rnthking · 一句话出标题+正文+9张风格统一配图，20万+创作者在用
⭐ 20万+用户社交分发7/17更新
是什么：把红鸦AI的小红书图文生成能力接入Codex。一句话给出主题，自动产出「标题+正文+6-9张风格统一的配图」——文案有「人味儿」不像AI写的，一套图背景色、排版、调性统一不用一张张对齐。
最适合：小红书运营、品牌营销、知识博主——尤其是那些「内容不愁但配图太耗时」的人。
亮点：自研视觉一致性算法确保多图风格统一；商品带货模式可关联真实商品图不出假货；先出大纲让你改再出图不浪费积分；Agent端和网页端打通，生成的图文同步到 hy.ithinkai.cn 可预览、下载、一键发布。
📦 安装
先在 hy.ithinkai.cn 注册获取API Key（注册即送免费试用积分），然后在Codex中说「请帮我安装红鸦小红书图文Skill」让AI自动下载配置

🎯 今天就能试：「帮我写一篇三伏天养生茶的小红书，先给我看大纲」→AI出标题+正文大纲+每页图片说明→你微调→确认后一键出6-9张统一风格配图。
📌 实操示例
输入：用红鸦帮我写一篇关于「办公室午休高效休息法」的小红书，目标人群是打工人，风格要轻松接地气，先给我看大纲
成果：大纲预览——标题「午休30分钟＞晚上多睡2小时，打工人高效回血指南」+正文3段（痛点引入→3个方法→亲测效果）+6页配图说明（封面大字报、方法对比图、时间分配图、成果图等）→你改完确认→一键生成6张风格统一的图文，保存到hy.ithinkai.cn「我的创作」可下载发布。

codex-team-mode — 4角色团队协作
oil-oil · 把大任务拆给4个专精Agent，主线程只保留决策和验收
⭐ 新发布（7/24）日常自动化MIT开源
是什么：一个让你把复杂任务拆成「多个专精子Agent并行工作」的协调Skill。4个角色分工明确——Explorer（只读搜集证据）→ Executor（写权限干清晰有界的活）→ Complex Executor（架构清楚的复杂实现）→ Reviewer（独立复核挑高后果风险）。最妙的是它会先算协调成本——如果派活的沟通成本超过了活儿本身的价值，就直接让主线程自己干，不浪费。
最适合：多步骤知识工作——比如「整理本周客户反馈+写分析报告」「做竞品调研+输出对比表+写策略建议」——这些都是一个人从头做到尾容易脑带宽不够的任务。
📦 安装
npx -y skills@latest add oil-oil/codex-team-mode --agent codex --global
安装后重启Codex，在对话中用自然语言描述多步骤任务即可自动触发
🎯 今天就能试：「整理这周5个客户反馈邮件，写一份客户满意度分析报告」→Explorer搜集所有邮件提取关键信息→Executor写初稿→Reviewer独立读一遍挑逻辑漏洞和数据不一致→主线程你最终拍板。
📌 实操示例
输入：帮我做一份新能源汽车行业的竞品分析：搜集蔚来、理想、小鹏Q2财报关键数据，做对比表，再写一份300字的策略建议
成果：主线程先评估协调成本（中等，值得派）→Explorer分别抓取三家财报的关键指标（营收、毛利率、交付量、研发费用）→Executor做对比表格+初步分析→Reviewer独立核实数据来源和对比逻辑（发现一处毛利率口径不一致的隐患，标注）→主线程收到一份带核验标注的完整竞品分析报告。以前手动做需要1-2小时，现在10-15分钟出初稿。

NotebookLM 每日进步
🧪 同一套素材，四种完全不同的产出
你可能知道NotebookLM能生成Audio Overview播客，但很多人没注意到格式切换这个隐藏按钮。同一套素材可以生成四种不同格式：Deep Dive（默认，双人对谈深度解读）、The Brief（单人，2分钟内简短摘要）、The Critique（双人批判性审查，专挑你素材里的漏洞）、The Debate（双人从正反两面辩论）。操作：新建Audio Overview→点齿轮图标→选格式→生成。一套行业报告→早上听Brief快速了解→下午听Deep Dive深入研究→发之前用Critique挑刺。
🧪 Briefing Doc回存笔记本，递归提升质量
这是一个被严重低估的技巧：让NotebookLM先生成一份Briefing Doc（简报文档），然后把这份简报作为新素材回存到同一个笔记本。此时NotebookLM可以「在自己的总结之上再做总结」——第二轮生成的内容会更有层次、更聚焦核心论点。这个递归方法对信息密度高、来源分散的研究项目尤其有效，重复2-3轮效果最佳。
🧪 素材分工法：大模型讨论方向，NotebookLM整理素材
先跟ChatGPT/Claude/Codex讨论「想解决什么问题、拆成哪几个维度」→拿着这个框架去搜集素材加入NotebookLM→再对NotebookLM针对性地提问。NotebookLM的设计是素材整理工具，不是创作工具——让它从零开始想写什么反而会吃掉它的优势。把它当「研究助理」而不是「代笔者」，输出质量会明显提升。

WorkBuddy 实用技巧
⚡ 多专家会诊：让AI从三个角度同时分析同一问题
做重大决策时别只听AI的一面之词。WorkBuddy支持同时召唤多个专家角色分析同一个问题：比如面对「要不要接一个新行业的咨询项目」——同时召唤「乐观派行业分析师」「悲观派风险评估师」「财务测算专家」，三个角色并行分析，10分钟内给你一份多维度报告。操作：新建任务→在专家中心依次添加三个专家→描述问题让它们各自分析→汇总对比。这个技巧的精髓在于强制多视角交叉验证，避免单一视角的盲区。
⚡ 给AI看例子，比说一堆要求管用
当你想要某种「感觉」但无法精确描述——比如某种文风、排版风格、汇报格式——最省力的方法是直接把一个你满意的样本丢给WorkBuddy，说「照这个来」。一篇好的参考文章，胜过500字的需求说明。AI更擅长「模仿」而不是「从零想象」。这个技巧搭配本期④号Skill（yao-meta-skill）效果翻倍：把参考样本作为Skill的规范锚点，以后每次调用都自动对齐风格。

🎯 PPT-Skill + redya-xiaohongshu 串联：一次汇报，多处开花
用今天介绍的①+②号Skill组合，把一份PPT内容同时变成小红书推广素材

第1步：用PPT-Skill生成汇报PPT——输入主题「国企数字化转型实践汇报，目标受众集团领导，场景年度总结会」→7阶段流水线产出15页咨询级PPT+演讲稿。
