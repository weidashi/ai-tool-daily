最适合：公众号号主、教程作者、深度长文创作者——每次写完文章还在手动调字号行距配色的人。

deep-reading-coach · 深度阅读教练
FanPUYen · 检视阅读→分析阅读→主题阅读，像有个教练陪你读书
阅读总结结构化笔记
是什么：一个帮你深度读书的Codex Skill。不是简单的「总结器」，更像一个阅读教练——先帮你判断资料怎么读，再帮你拆结构、抓概念、看论证，最后把阅读结果和你的目标联系起来。支持快速判断一本书值不值得读、制定阅读路线、生成结构化读书笔记、比较同一主题的多本书。
最适合：读书多但读完就忘的人、需要做主题研究的知识工作者、想真正「消化」一本书而不是「浏览」一本书的人。
📦 安装
git clone https://github.com/FanPUYen/deep-reading-coach.git ~/.codex/skills/deep-reading-coach
安装后重启Codex，在对话中输入「$deep-reading-coach」或直接说「帮我读这本书」即可触发
🎯 今天就能试：找一本你一直想读但还没翻开的PDF或电子书，对Codex说「帮我看看这本书，先告诉我值不值得花时间读」。它会先做检视阅读——判断这本书讲什么、结构怎么样、核心观点是什么——然后告诉你是否值得深入。如果值得，继续让它拆结构做分析阅读。
📌 实操示例
输入：「使用deep-reading-coach帮我深度阅读《思考，快与慢》PDF。先做检视阅读，然后帮我拆解第1-3章的核心概念和论证结构。」
成果：一份结构化阅读笔记——包含：① 检视阅读（值不值得读+阅读建议）② 核心概念拆解（每个概念的原文出处+通俗解释）③ 论证结构（作者怎么证明的+逻辑链）④ 你个人关心的问题和本书的关联。不再是读完就忘的摘要。

NotebookLM 每日进步
🧪 每个Notebook现在自带一台云电脑
NotebookLM 7月16日正式更名Gemini Notebook，核心理念不变。但最大变化是：每个笔记本背后都有一台安全的云端电脑——预装100+软件技能，能写代码、跑分析、画图表，不再只是「读你给的资料」。对知识工作者最实用的三个变化：① 可生成Slide Decks并导出PPTX（从此资料→PPT一条龙）；② Data Tables自动横向对比多份资料；③ 从空白聊天启动研究——说一个模糊想法，它主动搜Google找来源、建知识库。
🧪 Short Video Overviews 全量开放
60秒竖屏短视频自动生成，把整个Notebook的内容浓缩成适合手机刷的知识短片。做知识科普、培训材料、内容分发的利器。说「帮我生成Short Video Overview」即可。三种风格可选：叙事型、问答型、教程型。
🧪 「Explain > Summarize」原则
给NotebookLM下指令时，说「解释这个概念」比「总结这个文档」效果好几倍。总结只是压缩文字，解释需要理解因果+类比+举例。对于复杂资料，先用「Explain」拆解核心概念，再用「Summarize」收尾。

WorkBuddy 实用技巧
⚡ 「追加约束」比「重写」高效10倍
不满意WorkBuddy的输出？别让它重写。直接追加约束：「把这段缩短到100字」「把语气改成更正式」「把第二段的分析数据换成具体数字」。追加约束让AI在已有框架上精准调整，重写往往扔掉好的部分、生成新的问题。口诀：不满意先加约束别重写，加了3次还不满意再考虑重写。
⚡ 三种模式口诀：简单活Craft / 复杂活Plan / 重复活Automate
Craft模式说干就干——排版一篇文章、改一段文案；Plan模式先出方案让你确认——写报告框架、做PPT大纲；Automation模式把每天重复的事定时自动跑——每天早上生成AI资讯日报、每周五汇总工作周报。记住这个口诀，模式选对，效率翻倍。
