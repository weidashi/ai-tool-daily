Qwen3.8-Max 首次开源——2.4万亿参数旗舰，一句话从空文件夹交付项目
阿里巴巴 · 8月3日发布 · 千问系列迄今最大最强
⭐ 本周最重要开源模型自主编程
是什么：阿里发布新一代基座大模型 Qwen3.8，总参数 2.4 万亿，其中旗舰 Qwen3.8-Max 采用稀疏 MoE 架构，单次激活约 950 亿参数，支持最长 100 万 Token 上下文，原生集成多模态视觉理解。最大看点：Qwen3.8-Max 权重首次对全球开源——这是千问 Max 级别旗舰模型第一次开放。同时实现自主编程新突破：程序员一句话指令，模型可从空文件夹独立完成真实项目交付。
为什么重要：过去开源的都是中端模型，旗舰模型首次开源意味着中小团队也能用上顶级模型能力自建系统，不必受制于闭源 API 的定价和限流。
🔗 使用方式
即日起全球开发者可通过千问 AI 平台获取 API 服务；模型权重将于下周正式开源
关注 Qwen 官方仓库，权重放出后即可本地部署或用 Ollama 等工具加载
🎯 今天就能试：去千问 AI 平台（chat.qwen.ai）体验 Qwen3.8-Max 的自主编程能力——给它一个「从零做一个带登录、数据库、部署配置的待办事项 Web 应用」的指令，看它是否真的能独立从空文件夹交付。
📌 实操示例
输入：「从空文件夹开始，帮我搭建一个完整的个人博客网站：前端用 React + Tailwind，后端用 FastAPI + SQLite，包含文章列表、详情页、标签、评论功能，并写好 Dockerfile 和部署说明。一步都不要省略，直接开始。」
成果：模型自动完成项目初始化、依赖安装、前后端代码编写、数据库建表、容器化配置，最终交付一个可本地运行并部署的完整博客项目。全程无需人工逐步下达指令。

MiniMax H3 开源视频模型——上线三天登顶 Hugging Face 榜首
MiniMax · 8月7日开源 · 超百家企业 Day 0 接入
🔥 三天登顶视频生成开源模型
是什么：MiniMax 开源的 H3 视频生成模型，上线三天冲上全球最大开源平台 Hugging Face 热度榜首，超百家企业实现 Day 0 接入，连 Stable Diffusion 创始人都公开致敬。
为什么重要：视频生成模型开源是今年的风向标。H3 三天登顶说明：① 开源视频模型的质量已经追平甚至反超闭源；② 中国团队的模型在国际开源社区影响力持续上升；③ 对内容创作者意味着高质量视频生成正在变成「免费、可本地部署」的能力。
🔗 获取方式
在 Hugging Face 搜索 MiniMax H3，获取模型权重与推理示例
可配合本地推理框架部署，或通过 MiniMax 官方 API 直接调用
🎯 今天就能试：如果你的机器有足够显存，下载 H3 权重本地生成一段视频；没有的话用 MiniMax 官方 API 试一条「一只猫在夕阳下的海边慢跑」的 5 秒视频，感受开源模型的生成质量。

阿里千问开放平台——把租房、寄快递、理财装进 AI 对话框
阿里巴巴 · 8月10日上线 · 大模型从问答到履约的闭环
⭐ 生态里程碑智能体平台本地生活
是什么：阿里千问开放平台正式上线，面向开发者开放手机、PC、AI 眼镜三大终端接入能力，把租房、寄快递、租车、理财等现实服务搬进 AI 对话。首批入驻生态横跨物流、房产、汽车、本地生活、理财等十余个赛道，顺丰、闪送、自如、哈啰租车、天鹅到家、盈米基金等第三方伙伴全部完成接入。
怎么用：用户只需在千问 APP 里 @对应服务，或点击右上角圆点角标唤起智能体，就能直接发起需求。比如顺丰智能体会记忆你的常用地址，一句「帮我给上海客户寄文件」就能推进寄件全流程。
为什么重要：AI 跳出纯文本对话，直接对接现实服务——这是大模型从「回答问题」走向「完成任务」的关键一步，也标志着竞争焦点从模型能力转向生态与落地场景。
🔗 使用方式
打开千问 APP，更新至最新版本，在对话中 @ 相应服务或点击右上角圆点角标唤起智能体
开发者可通过标准化协议把已有 Agent 迁移至千问平台，平台配套账号体系、AI 支付、订单链路
🎯 今天就能试：打开千问 APP，试着对顺丰智能体说「帮我给上海的张先生寄一份文件，用我最常用的地址」，体验从对话到真实寄件的完整流程。

DeepSeek-V4-Flash 登顶全球调用榜——8.83万亿 Token 周调用量
DeepSeek · 8月10日数据 · 中国大模型连续十五周居首

是什么：OpenRouter 数据显示，8月3日至9日 DeepSeek-V4-Flash 正式版以 8.83 万亿 Token 周调用量登顶，环比大增 570%。中国大模型周调用量连续十五周超美国居全球首位。
为什么重要：这不是单个模型的胜利，而是整个中国开源生态的集体胜利。V4-Flash 的高性价比让它成为全球开发者的默认选择，570% 的环比增长说明正在快速渗透。
对普通用户：如果你在 WorkBuddy 等工具里用自定义模型，DeepSeek-V4-Flash 依然是最值得考虑的「便宜大碗」选项——日常写作、润色、代码生成都能胜任，成本远低于闭源旗舰。
🔗 使用方式

⚡ 让 WorkBuddy 记得你的偏好：用好记忆系统
WorkBuddy 的记忆分三层：用户级记忆（跨项目全局生效）、工作区 MEMORY.md（当前项目长期规则）、每日日志（自动记录做了什么）。如果你希望它「以后都这样」的习惯（比如文章风格、代码规范、回复语气），明确告诉它「记住这个偏好」，它会写入用户级记忆，之后所有项目都遵守。这是本周开源生态「沉淀规则」思路在个人工具上的对应——把规则写下来，一次生效，永久复用。
