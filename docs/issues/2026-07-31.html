智能体落地 Skills
①
agent-browser — 浏览器自动化 Skill
社区热门 · 持续更新 · 支持多页面操作
🔥 热门🌐 浏览器⚡ 自动化
是什么：让 AI 直接操控浏览器——打开网页、填表单、点按钮、截图、抓取数据、跨页面完成多步骤操作。不需要写 Selenium 脚本，一句话描述任务，它就执行。
最适合：需要定期从网页抓取数据、自动填写表单、批量截图汇报的场景。比如"帮我每天早上抓取这个数据看板截图发到群里"。
📦 安装
npx -y skills@latest add agent-browser --skill agent-browser --agent codex --global
安装后用 $agent-browser 触发，描述任务即可
🎯 今天就能试：把一个你每天手动打开查看的网页地址告诉它——"每天早上8点帮我打开这个数据看板，截图保存到桌面"——看看它怎么完成。
②
multi-step-task — 多步骤任务编排 Skill
社区发布 · 适合复杂工作流自动化
🔄 编排📊 工作流🎯 自动化
是什么：当一个任务需要分多个步骤执行、每步的输出是下一步的输入时，这个 Skill 帮你把整条链路串起来。它会自动拆解你的需求、规划步骤、逐步执行并汇报进度。
最适合："先搜索资料→整理成大纲→写成初稿→排版→导出 PDF"这种需要多环节串联的复杂任务。不再是手动一步步催 AI，而是一次说清，它自己走完。
📦 安装
npx -y skills@latest add multi-step-task --skill multi-step-task --agent codex --global
描述完整任务链，Skill 会自动拆解和执行
🎯 今天就能试：把下周要交付的一个完整任务丢给它——"帮我做一个Q3市场竞品分析，从收集资料到输出PPT，全程自动"——看它怎么拆步骤。
③
code-reviewer — 代码安全审计 Skill
社区维护 · 对标 OpenAI Codex Security CLI
🔒 安全📋 审计⚡ 自动化
是什么：7月28日 OpenAI 开源了 Codex Security CLI——一个命令行代码安全扫描工具。这个 Skill 是社区基于同样理念做的 Codex 适配版：扫描代码仓库、追踪问题、验证修复，全流程自动化。
最适合：有代码仓库需要做安全审查的团队。不需要手动跑安全扫描工具，一句话让 AI 帮你扫描整个项目并生成报告。
📦 安装
npx -y skills@latest add code-reviewer --skill code-reviewer --agent codex --global
指向项目目录，自动扫描并生成安全报告
🎯 今天就能试：把你最近一个项目的代码仓库路径告诉它——"帮我扫描这个项目的安全漏洞，按严重程度排序"——看看它发现什么。
④
data-pipeline — 数据处理管线 Skill
社区新发布 · CSV/JSON/Excel 全格式支持
🎯 新发布📊 数据处理🔄 管线
是什么：把"读取数据→清洗→转换→分析→可视化→导出"整条链路封装成一个 Skill。支持 CSV、JSON、Excel 等格式输入，自动生成清洗规则、统计摘要和可视化图表。
最适合：每周/每月需要处理同一批数据并出报告的人——配置一次管线，之后每次只换数据文件即可。
📦 安装
npx -y skills@latest add data-pipeline --skill data-pipeline --agent codex --global
指定数据文件路径和期望输出，自动跑完管线
🎯 今天就能试：把一份你手上最头疼的脏数据丢给它——"帮我清洗这份销售数据，去掉空行和重复项，按地区汇总月度趋势，导出 Excel"——看它怎么处理。
浏览器抓数据→ 数据管线清洗→ 多步骤编排分析→ 代码审计安全→ 全自动化交付

本周AI行业重大动态
🤖 OpenAI 推出 Presence：企业级智能体平台
7月23日发布。Presence 不是"更强的聊天模型"——它是一套企业级智能体部署框架：包含策略规则、审批动作、模拟环境、评估护栏和升级规则。核心解决的是"AI 智能体在生产环境中怎么安全运行"的问题。对普通用户的意义：以后用 Codex 跑长任务时，可以设护栏——"只能读不能删""花钱超过100元就暂停"——AI 会在边界内自主执行。
📈 Codex 用户5倍增长：长任务暴增10倍
OpenAI 发布了 Codex 智能体平台的使用数据：2026年上半年活跃用户增长5倍，运行超过8小时的长任务暴增10倍。开发者人均产出增长13-50倍。这意味着 AI 智能体已经不是"尝鲜"——越来越多团队在用它跑真正的长周期任务。如果你还没开始用 Codex 做自动化，现在是一个不错的入场时机。
🌟 Anthropic Managed Agents 全面升级
Anthropic 本周升级了 Managed Agents 平台——开发者可以更方便地部署 Claude 智能体到生产环境，支持自定义工具、记忆管理和多步骤编排。同时 Claude Sonnet 5 成为所有用户默认模型，性能接近 Opus 4.8 但成本只有一半。对普通用户的意义：用 Claude 做自动化任务的成本大幅降低。
💡 本周趋势总结：AI 行业正在从"谁的模型更强"转向"谁的智能体更靠谱"。OpenAI 的 Presence、Anthropic 的 Managed Agents、Google 的多模型矩阵——所有人都在押注同一件事：让AI不只是回答问题，而是真正完成任务。对于个人用户，这意味着安装一个 Skill 不再只是"多了个功能"——而是在搭你自己的智能体团队。

NotebookLM 每日进步
🎙️ Audio Overview 四种模式：讨论/简报/批评/辩论
NotebookLM 的播客功能现在有四种模式可选——深度讨论（两位AI主持人深入分析）、简报（5分钟快速摘要）、批评（AI找资料中的漏洞和偏见）、辩论（两位AI持不同立场辩论）。实操建议：先用"简报"模式快速了解一份新资料值不值得深读，再用"批评"模式检验你的分析报告有没有盲区。
📊 思维导图 + 报告：一份素材多种产出
同一个笔记本可以同时生成思维导图、结构化报告和闪卡。核心思路是"榨取"——把一份研究素材导入后，先用思维导图理清结构，再生成报告交给团队，最后用闪卡自测理解程度。三步走完，一份资料的价值就被充分提取了。
