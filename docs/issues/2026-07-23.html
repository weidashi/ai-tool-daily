腾讯云 CodeBuddy NPC — 研发智能体
腾讯云 · 7月22日发布 · 可自主交付PR
🔥 新发布🤖 数字员工💻 软件工程
是什么：自带完整软件工程思维的数字研发助手——在项目 Issue 里 @它下发开发需求，它就能自主走完需求拆解 → 方案设计 → 代码编写 → 提PR → 自动化测试全流程，并根据 CI/CD 报错持续迭代修复，直到产出符合验收标准的完整工程。
亮点：Token 用量从 2 万多压缩至约 2000（降幅超 90%）；支持多智能体组队（项目经理 / 后端开发 / 测试工程师）；已打通 GitLab 企业版、Jenkins X、Terraform Cloud、CODING DevOps。
🚀 怎么用
在 GitLab / CODING 的 Issue 中 @CodeBuddy NPC，粘贴需求描述 + 验收标准，等待它提交 PR
已接入 Jenkins X 等项目，CI/CD 报错会自动触发它自我修复、继续提交
🎯 今天就能试：把一个「修个 bug + 补个单测」的小 Issue @给它，盯一眼它拆解出的步骤和第一版 PR，体会"新同事"的工作方式。
📌 实操示例
输入：「@CodeBuddy NPC 登录接口偶发 500，请定位根因、修复并补上对应单测，验收标准：CI 全绿、覆盖率不低于 80%」
成果：自主完成代码定位、编写修复、提交 PR、跑通自动化测试，若 CI 报错会自我迭代直至验收通过，全程几乎不消耗你的 Token。

OpenAI Presence — 企业智能体平台
OpenAI · 7月发布 · 面向企业部署
🏭 企业级🔒 护栏机制🤝 人工接管
是什么：用于在客户服务和内部业务工作流中部署、管理 AI 智能体的企业平台：汇集企业知识、SOP、已批准操作、模拟测试、评估工具、护栏和升级规则。
亮点：智能体仅获得完成任务所需的信息；客户决定哪些操作独立执行、哪些需审批、何时转人工；Codex 可通过 Presence 插件调查信号并提出改进建议。
💡 适用场景
客服自动应答 · 工单分流 · 内部流程审批 · 知识库问答
关键设计：不是让 AI 全权处理，而是「哪些自主、哪些审批、何时转人工」都由企业说了算
🎯 今天就能试：如果你在用 Codex，试着让它通过 Presence 插件拉取一段业务信号做分析——感受"智能体管智能体"的企业运营方式。

Nanobrowser — 开源浏览器自动化
开源社区 · 13K★ 登顶热榜 · Chrome 插件
🔥 13K星🧩 Chrome插件💰 开源免费
是什么：完全免费开源的 Chrome 插件，多 Agent 协作（Planner + Navigator）用自然语言操控网页——填表格、抓数据、走流程都能交给它。对比 OpenAI Operator 每月 200 美元，有明显价格优势；支持自有 API Key 低成本运行。
亮点：代码全开源、数据本地可控、按自己用量付费，是把浏览器自动化能力"私有化"的低成本方案。
📦 安装
npx -y skills@latest add nanobrowser --agent codex
也可直接在 Chrome 应用商店搜索 Nanobrowser 安装，配好自有 API Key 即可
🎯 今天就能试：用 Nanobrowser 让 AI 自动帮你填表格、抓取网页数据——先从一个简单的"定时抓取某页面表格"开始。

WorkBuddy 团队打造 · 全量开放无需邀请码
🎨 设计✅ 全量开放🧠 多模态
是什么：全面开放、无需邀请码的设计 Agent 平台：提供品牌设计、影视创意等五大场景模式，支持自定义多模态模型和 Agent 推理深度，内置 Skill 市场与记忆系统。

支持接自定义多模态模型，Agent 推理深度可调，重度需求开高、轻量草图开低

行业动态
⚡ GigaToken 发布：分词速度最高提升约 1000 倍
语言模型分词速度迎来数量级提升：GPT-2 分词速度达 24.53 GB/s，比 HuggingFace Tokenizers 快 989 倍、比 tiktoken 快 681 倍，且可无缝替代现有方案。实操意义：大批量处理文本时（数据清洗、语料预处理、Agent 长上下文加载），等待感会明显消失。
📦 微软 MagenticLite 模型全面开源
MagenticBrain 和 Fara 1.5 权重开放至 Hugging Face——不只是模型，应用、测试工具及堆栈中每个模型全部开放。实操意义：想在本地跑一套多智能体推理栈、或复现微软的智能体评测流程，现在有完整可复现的起点，不用再猜权重和配置。
📊 Claude 新增 Anthropic Economic Index 连接器
现在可以在 claude.ai 直接提问「哪些职业使用 AI 最多」，答案基于 Anthropic Economic Index 的真实匿名使用数据。实操意义：做行业研究、求职或团队 AI 转型规划时，可以用真实数据回答"AI 到底在哪些岗位先用起来了"。
💡 实用技巧一：把智能体当同事用
别只给它一句话任务——要给它「目标 + 边界 + 验收标准」，就像给新同事布置工作。目标说清"要什么"，边界说清"别碰什么"，验收标准说清"怎样算完成"。CodeBuddy NPC 能自我迭代，前提是你把"符合验收标准"这个终点定义清楚。
💡 实用技巧二：开源替代方案盘点
在动手付费之前先查一遍开源选项：Nanobrowser 替代 OpenAI Operator，省下 200 美元/月；本地分词用 GigaToken、本地智能体推理栈用 MagenticLite——先把能白嫖的生产力用到极致，再为缺口付费。
